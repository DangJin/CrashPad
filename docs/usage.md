# 使用指南

[返回项目首页](../README.md)

## 绘制现场

1. **选择道路**：从左侧模板选择最接近现场的路型，在右侧设置车道和方向。
2. **摆放车辆**：拖动车辆，或在右侧输入坐标、调整车头角度和来车方向。
3. **描述已经发生的动作**：在“已行驶路线”选择直行、转弯、变道或汇入，拖动虚线起点调整来源位置。
4. **标注后续计划**：在“后续动作”选择动作，拖动圆点调整终点、方块调整曲线。直行终点拖向旁边时，会自动切换为变道。
5. **补充现场信息**：标记碰撞点，点选车身受损部位，填写说明、地点和时间。
6. **设置红绿灯**：点击画布上的灯，或从左侧对象列表选择，在右侧调整灯色和朝向。未知灯色不会被假定为红灯或绿灯。
7. **检查演示**：播放已行驶、后续动作或完整演示，检查路线和方向。
8. **导出**：编辑顶部标题，选择格式、比例和清晰度后下载。

点击画布上的道路、车辆或红绿灯，也可以从左侧对象列表切换选中对象。手机端工具面板按需展开，属性区位于画布下方。

### 路线与方向

- **虚线**：到达当前编辑位置之前，已经行驶的路线。
- **实线**：尚未发生的后续计划。
- 左转、右转及左右变道按驾驶员视角判断。
- 匝道侧和进入 / 离开段按所选道路行驶方向判断。
- 变道结束后保持原车头方向；汇入可以设置进入主路后的朝向。
- 红绿灯按来车所在侧配置；小箭头表示标识朝向，文字始终水平显示。

### 演示模式

| 模式 | 内容 | 基础时长 |
| --- | --- | --- |
| 已行驶 | 从路线起点到达当前编辑位置 | 4 秒 |
| 后续动作 | 从当前编辑位置沿计划路线运动 | 4 秒 |
| 完整演示 | 先播放已行驶路线，再衔接后续动作 | 8 秒 |

未设置后续动作的车辆在计划阶段保持原位。演示结束后自动恢复原场景并进入编辑，不将计划改写为已发生事实。演示仅用于表达过程，不还原真实车速或碰撞物理过程。

## 图片和 GIF 导出

### 比例

| 预设 | PNG / JPG 标准尺寸 |
| --- | --- |
| 原图 | 宽 1760 px，高度随标题和说明调整 |
| 小红书 · 3:4 | 1080 × 1440 px |
| 抖音竖屏 · 9:16 | 1080 × 1920 px |
| 方形 · 1:1 | 1080 × 1080 px |
| 横图 · 4:3 | 1440 × 1080 px |
| 宽屏 · 16:9 | 1920 × 1080 px |

PNG / JPG 可选择两倍高清尺寸。小红书和抖音预设使用独立竖版排版，放大标题和正文；长标题、说明会自动换行并调整布局，画布保持等比缩放。

### 格式

- **PNG**：保留清晰线条和文字。
- **JPG**：提供另一种静态图片格式。
- **GIF**：导出已行驶、后续动作或完整演示，循环播放；标准长边最多 960 px，高清长边最多 1440 px，比例不变。终点及完整演示中间阶段会短暂停留，便于阅读。

GIF 在浏览器本地逐帧渲染，由 Web Worker 编码。生成时显示进度，支持取消，无需上传场景到服务器。

导出自动省略未设置的后续动作、空白现场说明及其标题、未注明灯色的红绿灯。已填写的说明、受损部位和已知信号状态正常保留。PNG、JPG、GIF 共用这套规则。

顶部标题最多 60 字，会同步显示在导出图片和文件名中；留空时使用“事故示意图”。静态图片使用当前编辑位置，GIF 根据选定模式演示路线。

## 草稿与快捷键

草稿通过浏览器 `localStorage` 自动保存，键为 `crashpad:draft:v1`，兼容旧版草稿。当前仅保存一个草稿，不提供账号登录或跨设备同步；清除浏览器数据会删除草稿。回放进度、播放速度及画布缩放不写入草稿。

| 操作 | 快捷键 / 方式 |
| --- | --- |
| 微移车辆或碰撞点 | 选中后按方向键 |
| 加速微移 | `Shift` + 方向键 |
| 撤销 | `Ctrl / Command` + `Z` |
| 重做 | `Ctrl / Command` + `Shift` + `Z` |
| 重置场景 | 画布工具栏“重置”，可撤销恢复 |

当前支持两辆车，不包含照片上传、多车场景或责任判定。所有图示均依据绘制者描述生成，位置与距离为示意，不代表事故责任认定。
