## 后续修复（2026-10-17）

上表保留原 review 证据；以下为当前状态：

- **路口冲突释放已修复**：所有连接段按共享/交叉区的尾部清空位置释放；同一接收车道继续保持汇流约束。释放点超过连接段端点时，继续计入驶出车辆的尾部距离。信号切相仍保留全红清空，出口堵塞仍禁止进入。
- **增加车道已修复**：普通连续组件按原车道顺序分配新增出口车道，并结合队列及后续路线选择；属于有序分流，不是允许车辆在任意连接段上自由横向变道。
- **短路段预判已补充**：最多向前看 3 个短连接段（单段不超过 180 米），把后续出口的车道需求传回前一段；按编译路网缓存结果。收费窗口仍沿用办理时间和队列规则。
- **弯道限速已调整**：弯道组件按离散路径曲率计算速度上限，并受两侧道路限速约束。使用 1.8 m/s² 的模型舒适度参数及画布示意几何，未经过真实路测标定。普通信号路口的固定转弯/直行限速保留，不在此次直接放开。

验证：39 项路网与仿真测试通过，包括新车道实际利用、短路段提前选道、释放后并发通行的空间间距、弯道速度约束，以及原有信号切换、出口回堵、拉链、收费站与旧草稿转换。静态检查和生产构建通过。

## 收费站提前选窗与进站准备

车辆进入收费站前的接入道路时，根据窗口服务时间、已预约/排队车辆和横向移动成本确定窗口。将窗口映射到有序的进站车道，在接入道路上逐车道准备，进入广场前须完成准备；进入收费队列后保持目标窗口，付款后恢复出站变道。保留安全间距与交叉让行规则。

这不是按“80%”硬编码的司机比例，车辆资格和窗口放行已在下节升级。此规则覆盖直接连接收费站的接入道路，未扩展为跨多个上游路段的收费窗口导航。

回归场景：3 进 / 8 窗 / 3 出，100 辆，窗口 ETC×4、人工×3、ETC×1，默认种子与流量。总清空时间 324.3 → 311.3 秒；入口交叉让行且速度低于 1 m/s 的累计时间 161.7 → 75.8 车·秒。数值只用于同配置回归，不代表现实通行预测。


## ETC 资格与低速放行

车流设置增加 `etcPercent`，默认 100% 以兼容旧的全 ETC 场景，不代表现实统计。固定种子独立分配资格，人数按总数乘比例四舍五入，不改变原有路线与驾驶风格随机序列。非 ETC 车辆仅选人工窗口，ETC 车辆也可选人工窗口；无人工窗口的必经路线会在开始前提示修正。

ETC 在窗口前后 40 米以 20 km/h 为目标速度，无拥堵时不停车；原 `etcSeconds` 改为同窗口的最小放行间隔，不再是停车办理时间。人工保持停车办理。两者都保留跟车、队列回堵和安全间距。车流比例、速度及间隔是实验参数，未模拟识别失败、设备故障或人工服务时间波动。

验证覆盖空闲 ETC 不停车、人工停车满时长、15 秒放行间隔、固定种子资格分配、非 ETC 禁入专用窗口及不可通行配置提示。
