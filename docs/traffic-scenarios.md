# 通勤场景预设

车流实验室顶部「通勤场景」或属性面板「快速开始」载入。每个预设都是可编辑的普通路网；加载替换当前草稿，可撤销恢复，不覆盖 A/B 存档。桌面先展示全路网，手机直接聚焦关键路口，避免道路缩小到看不清。

## 高速早高峰

郊区三车道 → 住宅区匝道汇入 → 800 米主路 → 商务区出口 → 继续进城。主路各段 100 km/h，匝道 40 km/h。主路 180 辆、105 辆/分钟；匝道 60 辆、35 辆/分钟。主路 25%、匝道 15% 驶出商务区，其余继续进城。采用合作汇入，不额外叠加收费站或收窄。

观察右侧车道、匝道等待、出口准备；可修改汇入策略或从不同入口跟车。

## 城市主干道早高峰

居住区 → 小区路口 A → 400 米 → 横向主干道路口 B → 300 米 → 商业街路口 C → 办公区。主干道双向各三车道、50 km/h；侧路 40 km/h，中间路口侧路各两车道，其余各一车道。共 240 辆：居住区 120、办公区反向 30、六个侧路入口各 15。

居住区 35 辆/分钟，反向 12；中间侧路 15，其余侧路 8。含直行和双向转向目的地，三个路口使用直行/左转分放，外侧路口直行绿灯 35 秒、中间 25 秒、左转 12 秒。不是绿波协调。

观察红灯积队、绿灯释放及上下游队列。可修改信号时长、目的地比例，保存 A/B 比较。

## 参数与验证

以上是用于解释机制的实验参数，不是实测流量或现实预测；每个场景是有限 240 辆片段，不是持续一小时的需求模型。默认种子 42，驾驶风格 20% 稳健 / 60% 常规 / 20% 积极，具体名称跟随系统定义。

默认种子完整运行：高速 569.6 秒清空，峰值低速车辆 39；城市 1347.6 秒清空，峰值低速车辆 187（包含不同入口和路段）。两者均 240 辆完成、无失败、无超时。种子 43、44 仅验证路网编译和路线合法，未据此声称所有种子均完成。

连续路段测试同时暴露路线准备过晚：路线预判现在查看最多三个相邻路段（每段不超过 800 米、不穿透收费广场）；车辆入场按路线选择准备车道，必需的变道在有空间时开始。现有转向、匝道、收费站及车距测试保留。

机制参考：[FHWA 交通瓶颈说明](https://ops.fhwa.dot.gov/publications/fhwahop18013/chap2.htm)。实现不依赖外部服务。
