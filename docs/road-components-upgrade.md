# 道路组件细节升级

## Review

目标：俯视图能清楚表达道路结构；路面、标线与车辆轨迹一致，编辑中的未完成路网也能看懂。

| 问题 | 影响 | 本轮处理 |
| --- | --- | --- |
| 汇接路面只在整张路网编译成功后绘制 | 未完成的路口会让另一处匝道变成断头路 | 视觉几何独立于仿真校验，已知端点始终绘制 |
| 匝道直接弯向主路 | 缺少加减速段、分流鼻端和渐变关系 | 平行辅助车道＋渐变段；共用车辆路径与路面几何 |
| 节点、连接道路分别画封闭边框 | 接缝、横线和车道标线中断 | 连续边线、分道线、方向箭头；选中轮廓单独表达 |
| 路口只有方形路面 | 不易辨识停止位置及通行方向 | 停止线、横道、车道方向箭头，与仿真停止端点对齐 |
| 收费站仅有 ETC/人工标签 | 看不出收费岛和窗口位置 | 收费岛、亭体、栏杆；标签与车辆通行空间分离 |
| 车辆只是色块，纹理干扰识别 | 朝向弱、道路层次不明确 | 车窗、车灯、车轮，降低路面纹理对比 |

## 实施顺序

1. 提取可复用的路面和标线几何，修复未完成路网中的绘制缺失。
2. 共用匝道辅助车道/渐变路径，补齐导流区域。
3. 统一直路、车道变化、路口、收费站及车辆的显示细节。
4. 验证几何连续、旧草稿兼容、车辆完成率、交叉间距与桌面/手机交互；截图检查完整和未完成两种状态。

## 范围

本轮是结构清晰的交通示意图升级，不引入卫星纹理、3D 引擎或服务端。
保留道路参数、模拟需求、选择编辑、撤销与缩放操作。
加减速段为示意几何，不宣称符合某一地区的道路工程设计标准。

## 验证结果

- 路网单元测试 30 项通过；新增辅助车道轨迹边界测试通过。
- 原有浏览器回归 38 项通过、2 项跳过；新增组件细节测试 8 项通过（桌面和手机）。
- `npm run check`、`npm run build` 通过。
- 检查了匝道、收费站、十字路口截图；未连接路网仍保留完整匝道结构。
